# zaydek/claude-apps-demo

Launcher plugins for apps zaydek shares, made with claude-apps. They hold no keys and no builds; access is by GitHub username or by an SSH public key the author pasted.

## hello-cli

hello-cli, shared by zaydek

```
claude plugin marketplace add zaydek/claude-apps-demo
claude plugin install hello-cli@claude-apps-demo
```

Then `/hello-cli:open`. When zaydek says the launcher changed: `claude plugin marketplace update claude-apps-demo` and `claude plugin update hello-cli@claude-apps-demo`.
